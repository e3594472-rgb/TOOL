# Анимация выбора

Для **Pick a Student** добавить эффект перебора имён перед финальным выбором.

После нажатия кнопки `PICK` имена должны быстро сменять друг друга:

`Anna → Max → Sophie → Leo → ...`

Затем смена постепенно замедляется.

После остановки проигрывается короткий звук **ta-dam**, и крупно показывается выбранный ученик:

# MAX

Для режима **Pick & Speak** использовать похожий эффект:

1. После нажатия `PICK & SPEAK` быстро прокручиваются имена учеников.
2. Прокрутка постепенно замедляется.
3. Финальное имя фиксируется крупно на экране.
4. Проигрывается короткий звук `ta-dam`.
5. После этого снизу плавно появляется speaking question, например с лёгким `fade`, `slide` или эффектом переворота карточки.

Вся анимация должна занимать примерно **1–2 секунды**.

Не делать слишком много звуков, вспышек или длинных эффектов. Нужен один короткий эффект ожидания и один приятный звук результата.
