# Icon Correction — Replace the Current Illustrations with Proper UI Icons

The current visuals in the tool cards are not working well enough.

The small illustrations/icons currently look too soft, vague, and slightly awkward.  
They do not feel like polished UI icons.

I want these elements to look cleaner, more modern, and more intentional.

## Main correction

Please replace the current hand-drawn / decorative icon blocks with **proper clean SVG icons**.

Do not create custom abstract mini-illustrations for these tool buttons if they end up looking clumsy.

Instead, use a good icon library and build the visual around strong, readable icons.

---

# 1. What I want instead

Each tool card should have:

- one clear icon;
- a clean icon container;
- better visual balance;
- a more polished and modern feel.

The icon should immediately communicate the function.

For example:

- **Pick Student** → student / person icon
- **Order** → ordered list icon
- **Pairs** → two users icon
- **Teams** → group icon
- **Pick & Speak** → speech bubble / message icon
- **Question** → question bubble / help icon

---

# 2. Use a proper icon library

Please use a consistent SVG icon library, for example:

- **Lucide**
- **Tabler Icons**
- **Phosphor**
- **Heroicons**

Preferred choice: **Lucide Icons**

Do not use emoji.

Do not draw improvised icons with CSS if they look weaker than real SVG icons.

---

# 3. Specific icon suggestions

Use icons similar to these:

- **Pick Student** → `UserRound`
- **Order** → `ListOrdered`
- **Pairs** → `Users`
- **Teams** → `UsersRound`
- **Pick & Speak** → `MessagesSquare`
- **Question** → `MessageCircleQuestion`

If a slightly better icon exists in the chosen library, it is fine to use it.

But all icons must belong to the same icon family.

---

# 4. Icon style requirements

Icons should be:

- clean;
- simple;
- readable;
- modern;
- consistent;
- slightly playful, but not childish.

Use:

- rounded or friendly line icons;
- medium stroke weight;
- balanced proportions.

Do not use overly detailed icons.

Do not use mismatched icon styles.

---

# 5. Icon container

The icon should sit inside a cleaner, more polished container.

The current rounded shape can stay in principle, but it should be improved.

Recommended container style:

- rounded square or soft blob-like square;
- subtle background tint;
- thin border or inner outline;
- soft shadow;
- enough padding around the icon.

The icon container should feel like a polished badge, not like a random sticker.

---

# 6. Improve the current look

The current icon badges feel too pale and not defined enough.

Please improve them by adjusting:

- contrast;
- border clarity;
- icon size;
- spacing;
- visual weight.

The icon should be easier to notice at a glance.

---

# 7. Colour direction

Use the same overall palette as the app, but make the icon areas more visually confident.

Possible approach:

- very light pastel background in the icon tile;
- darker accent icon colour;
- subtle outline;
- one accent colour per card type if needed.

For example:

- teal;
- blue;
- coral;
- warm yellow;
- soft violet.

Do not make the icons too washed out.

Do not make them neon-bright either.

---

# 8. Size and proportion

The icon should be large enough to feel important.

Do not leave too much empty space around it.

Recommended approach:

- enlarge the icon slightly;
- keep the container compact but not tiny;
- maintain good balance between icon, title, and subtitle.

---

# 9. Keep the functionality

This is a visual improvement only.

Do not change:

- the navigation logic;
- the tool names;
- the actual behaviour of the app.

Only improve the icon area so the cards feel more polished and attractive.

---

# 10. Final visual goal

The tool cards should feel:

- cleaner;
- more modern;
- more professional;
- more appealing to use during class.

The result should look like polished educational app UI, not improvised decorative shapes.

## Important short version

Replace the current custom mini-illustrations with clean SVG icons from one consistent icon library, preferably Lucide, and redesign the icon badges so they look polished, readable, and visually stronger.
