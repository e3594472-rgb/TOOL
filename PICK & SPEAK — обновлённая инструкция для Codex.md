# PICK & SPEAK

## 1. Цель проекта

Создать веб-инструмент **Pick & Speak** для преподавателя, который можно использовать **прямо во время онлайн- или офлайн-урока**.

Главная идея:

> Открыть сайт, быстро ввести имена учеников, выбрать нужный режим и сразу использовать инструмент на уроке.

Инструмент должен помогать преподавателю:

- случайно выбирать ученика;
- определять порядок ответов;
- делить учеников на пары;
- делить учеников на команды;
- случайно соединять ученика и speaking question;
- выбирать случайный вопрос.

Это **не трекер**, не электронный журнал и не LMS.

---

# 2. ВАЖНО: как должен ощущаться сайт

По логике использования ориентироваться на сайты типа **online-stopwatch.com**:

- пользователь сразу видит инструменты;
- не нужно долго настраивать приложение;
- минимум лишнего текста;
- крупные понятные кнопки;
- приятный визуал;
- каждый режим выглядит как отдельный удобный инструмент;
- результат виден крупно и подходит для демонстрации экрана ученикам.

Интерфейс не должен выглядеть как корпоративный dashboard.

Не делать сложные настройки перед началом работы.

Главное:

**open → enter names → choose mode → use**

---

# 3. Основной сценарий использования

Преподаватель открывает сайт во время урока.

Например, сегодня на занятии:

```text
Anna
Max
Sophie
Leo
Emma
```

Он вводит эти имена и сразу может использовать любой режим.

Если один ученик отсутствует — его можно удалить.

Если новый ученик подключился позже — его можно добавить.

Список должен редактироваться **в любой момент, не выходя из выбранного режима**.

Это одно из главных требований проекта.

- удалить ученика;
- добавить ученика;

# 13. Если список учеников изменился

Если во время раунда преподаватель удалил ученика:

- удалить его из текущего раунда;
- не ломать логику.

Если преподаватель добавил нового ученика:

- добавить его в текущий список;
- новый ученик должен иметь возможность выпасть.

# 25. Логика Pick & Speak

В рамках одного раунда:

- ученики не повторяются;
- вопросы по возможности не повторяются.

Пример:

```text
Anna
What do you usually do at weekends?
```

Далее:

```text
Max
What is your favourite way to relax?
```

Далее:

```text
Sophie
If you could travel anywhere, where would you go?
```

Anna не должна выпасть снова, пока не ответят остальные ученики.

# 58. Главный критерий проекта

После запуска пользователь должен без инструкции понять:

**куда ввести имена → какой инструмент выбрать → как получить следующий результат.**

И весь процесс должен быть достаточно быстрым, чтобы преподаватель мог пользоваться **Pick & Speak прямо во время урока, не отвлекаясь от учеников.**
