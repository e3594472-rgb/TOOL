# Pick & Speak

Быстрый веб-инструмент для преподавателя: случайный выбор ученика, порядок ответов, пары, команды и speaking questions.

## Запуск

```bash
npm install
npm run dev
```

Для production-сборки:

```bash
npm run build
npm run preview
```

Списки учеников и вопросов, а также настройка звука сохраняются локально в браузере.
